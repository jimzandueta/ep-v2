Accessibility (WCAG 2.1 AA)

Everything shipped with this system is expected to pass AA. Major commitments are codified in the tokens and components already (focus ring, min target, reduced motion). Additional rules below:

AreaRequirementHow it's enforced
Color contrast4.5:1 for text, 3:1 for UI chromeToken audit; navy/white & orange/white verified AA
Focus indication3 px solid sky-300 offset 2 pxGlobal :focus-visible in tokens
Touch target≥ 44 × 44 CSS px.btn min-height 48
KeyboardTab/Shift+Tab, Enter/Space, Esc (modal)Native semantics preferred; Tabs & toggles use aria-selected/aria-pressed
Screen readerForm fields have persistent labels; errors announced via aria-describedbyPattern in input component
MotionRespects prefers-reduced-motionGlobal @media in tokens file
ResponsiveUsable to 360 pxStepper wraps, order summary collapses to drawer
LocalizationStrings externalizedNo hard-coded copy in components; all via ICU-message JSON

Engineering notes

System targets Next.js (TRD §1.4). Tokens ship as CSS custom properties and a Tailwind preset; components live in a shared React library with headless behavior + Radix primitives where available.

Token delivery

CSS custom properties on :root, mirrored as a Tailwind theme extension. Partner theming applied via [data-theme="rbc"] scoped overrides.

Server-render pricing

All product cards and summary rails read prices from the SSR response — never from the client. Keeps pricing authoritative (DG-5).

Idempotent CTAs

Submit buttons emit an X-Idempotency-Key; duplicate clicks are absorbed by DynamoDB IdempotencyKey table.

Disabled reasons

Cards that disable (e.g., Clear Credit without annual Credit Block) must set aria-disabled and render the reason inline. Never disable silently.

Grandfathered state

Existing clients see grandfathered products as context (card--active + badge--grand). Irreversible changes require a warning alert.

Partner (group code)

Group code step renders before products. On success, data-theme is applied at the layout root; all components re-render under the partner palette.
